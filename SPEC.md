## Semantics (must be identical everywhere)
- Task open statuses: not_started, in_progress, on_hold. Closed: completed, cancelled. `overdue` is NEVER stored; API returns `effective_status` = "overdue" when open and due_date < user's today.
- scheduled_date(task) = start_date or due_date. Day D tasks = open-or-closed tasks with scheduled_date==D, or queued_date==D.
- carried_forward(today) = open, scheduled_date<today, due_date null or >= today, queued_date != today. overdue = open and due_date<today. Original dates never auto-changed. Reschedule is explicit (PATCH dates) and logged in task_activity + reschedule_count++. "Add to today" sets queued_date=today.
- Productivity(D) = completed / (scheduled-for-D tasks excluding cancelled) *100 (0 if denominator 0). Cancelled excluded; overdue tasks count in the day they were scheduled; recurring occurrences are normal tasks. Daily report snapshot stored in daily_reports (unique user+date).
- Timezone: DateTimes stored UTC; "today" computed from user_preferences.timezone (IANA). Dates/times for tasks are user-local.
- Notification dedupe: notifications unique(user_id, dedupe_key), e.g. `morning:2026-10-17`, `evening:<date>`, `tomorrow:<date>`, `reminder:<reminder_id>`, `overdue:<task_id>:<date>`. task_reminders unique(task_id, kind, remind_at). Worker `python -m app.worker` is a one-shot cron (every minute): process due reminders (retry w/ backoff, max 5), daily summaries at configured local times, overdue alerts, materialize recurring tasks (30 days ahead), generate daily report; sends Web Push via pywebpush when subscriptions exist. NO in-process scheduler for critical work. WebSocket `/ws?token=` only pushes live "changed" events from API process; frontend also polls (react-query refetchInterval 30s).

## API (all under /api, JSON, Bearer JWT except auth+health). `/health` at root returns {"status":"ok","db":true}
Auth: POST /api/auth/register {email,password,name,timezone?}→{access_token,refresh_token,token_type,user}; POST /api/auth/login (same body email,password); POST /api/auth/refresh {refresh_token}→ new pair (rotation); POST /api/auth/logout {refresh_token}; GET /api/auth/me.
Tasks: GET /api/tasks?search&status&priority&project_id&category&tag&date_from&date_to&sort=(due_date|priority|created_at|title)&order&limit&offset; POST /api/tasks; GET/PATCH/DELETE /api/tasks/{id}; POST /api/tasks/{id}/duplicate; POST /api/tasks/{id}/complete; POST /api/tasks/{id}/reschedule {start_date?,due_date?,start_time?,end_time?}; POST /api/tasks/{id}/add-to-today; PATCH /api/tasks/{id}/board {board_column}; subtasks: POST /api/tasks/{id}/subtasks {title}, PATCH/DELETE /api/subtasks/{sid} {title?,done?}; same for checklist (/api/tasks/{id}/checklist, /api/checklist/{cid}); comments: GET/POST /api/tasks/{id}/comments; attachments: POST /api/tasks/{id}/attachments (multipart file), GET /api/attachments/{aid}/download, DELETE /api/attachments/{aid}; activity: GET /api/tasks/{id}/activity; time: POST /api/tasks/{id}/timer/start, /timer/stop, GET /api/time-entries?date_from&date_to.
Task JSON: id,title,description,project_id,project_name,project_color,category,priority(critical|high|medium|low),status,effective_status,board_column(backlog|todo|in_progress|review|completed),start_date,due_date,start_time,end_time,estimated_minutes,reminder_at,tags[],notes,queued_date,reschedule_count,completed_at,recurrence_rule_id,subtasks[{id,title,done}],checklist[{id,title,done}],attachments[{id,filename,size}],created_at,updated_at,tracked_seconds. Create/PATCH body = same writable fields (+ `recurrence`: {freq:daily|weekly|monthly,interval,by_weekday[0-6],end_date}|null).
Projects: GET/POST /api/projects; GET/PATCH/DELETE /api/projects/{id} (returns progress_percent, task_counts{by_status}, milestones); POST /api/projects/{id}/milestones; PATCH/DELETE /api/milestones/{id}; GET /api/projects/{id}/board → {backlog:[],todo:[],in_progress:[],review:[],completed:[]}.
Dashboard: GET /api/dashboard?date= → {now,date,today:{total,completed,pending,in_progress,overdue,productivity},tasks_today[],carried_forward[],overdue[],tomorrow:{date,planned[],carried[]},upcoming_deadlines[],weekly[{date,total,completed,productivity}]}.
Views: GET /api/today, GET /api/tomorrow (same shapes as sections above). Calendar: GET /api/calendar?start=&end= → tasks in range (scheduled/due in range) plus recurrence expanded already (materialized).
Notifications: GET /api/notifications?unread_only&limit; POST /api/notifications/{id}/read; POST /api/notifications/read-all; GET /api/notifications/unread-count; POST /api/push/subscribe {endpoint,keys:{p256dh,auth}}; POST /api/push/unsubscribe {endpoint}; GET /api/push/public-key; POST /api/notifications/test (creates in-app + push test).
Reports: GET /api/reports/daily?date= ; GET /api/reports/daily/export?date=&format=pdf|csv ; GET /api/reports (list dates). Report JSON: date,total,completed,pending,overdue,cancelled,completion_percent,time_spent_seconds,by_project[{project,total,completed}],tomorrow_planned[],generated_at.
Analytics: GET /api/analytics?range=7|30|90 → {daily[{date,total,completed,productivity}],weekly[{week,total,completed}],monthly[{month,total,completed,productivity}],completed_vs_pending{completed,pending,overdue,cancelled},by_project[{project,total,completed,productivity}],priority_distribution[{priority,count}],overdue_trend[{date,count}],workload[{date,estimated_minutes,tasks}],time_tracking[{date,seconds}],definitions{...text}}.
AI: GET /api/ai/status → {enabled,provider}; POST /api/ai/chat {message} → {answer,source:"llm"|"rules",data_used}; GET /api/ai/insights → {suggested_priorities[],approaching_deadlines[],tomorrow_plan[],overload:{flag,message},delayed_tasks[],weekly_summary}. All from DB; works without key (rules).
Settings: GET/PATCH /api/settings → {name,timezone,morning_time "HH:MM",evening_time,tomorrow_time,default_reminder_minutes,theme(light|dark|system),work_start,work_end,weekend_days[int],notify_morning,notify_evening,notify_tomorrow,notify_reminders,notify_overdue,recurring_defaults{}}.
Errors: {"detail": "..."} with proper status (422 validation, 401, 403, 404, 409, 429).
